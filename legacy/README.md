# Legacy Scripts

These scripts are deprecated and no longer receive new features. They are kept for reference.

| File | What it was | Replaced by |
|---|---|---|
| `activate.ps1` | Original entry point for the harness | `argos` (npm CLI) |
| `evenatan-ui.ps1` | Interactive RPG UI prototype | `argos` CLI + `argos-chat.ps1` |

Do not use these in new setups. Use `argos` instead.
