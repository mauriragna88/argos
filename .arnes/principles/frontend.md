# Golden Principles — Frontend

1. **Accesibilidad**: etiquetas, foco, contraste y navegación por teclado. No es opcional.
2. **Estados completos**: loading, error, vacío y éxito. Nunca solo el caso feliz.
3. **Tipos de extremo a extremo**: schema compartido (Zod) como fuente de verdad entre UI y API.
4. **Feedback claro**: mensajes de error accionables, no crípticos.
5. **Rendimiento razonable**: evitar re-renders innecesarios y bundles gigantes sin necesidad.
