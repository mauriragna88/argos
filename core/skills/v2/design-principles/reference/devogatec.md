# DEVOGATEC — Brand Direction

**Scope:** DEVOGATEC projects only. This file is a per-client brand reference, deliberately kept out of `design-principles` so the foundation stays client-neutral.

Load this file only when the work is for DEVOGATEC. It does not apply to other clients.

## Direction

Prefer:

- deep navy
- blue
- cyan
- white
- controlled orange/gold accents

## Personality

technology · trust · growth · professional · local · human · modern

## Avoid

- cyberpunk
- gaming aesthetics
- crypto aesthetics
- neon overload
- generic AI startup aesthetics

## How to apply

This is a default direction, not a template. Brand direction selects palette and tone; it does not license skipping hierarchy, spacing, restraint, or the anti-template test in `design-principles`.

If a DEVOGATEC page could belong to any other technology company once the logo is removed, the anti-template test in `design-principles` §13 has failed regardless of whether these colors were used.
