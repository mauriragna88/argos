# Golden Principles — Arquitectura

1. **Diseño primero**: para cambios de arquitectura, plan (SDD) antes de código. El contexto del turno incluye decisiones previas relevantes.
2. **No duplicar memoria**: el harness es el cuerpo, OSMA el cerebro. Nunca guardar memoria en el repo.
3. **Deuda consciente**: documentar trade-offs en ADR antes de elegir una vía.
4. **Componentes cohesivos**: una responsabilidad por módulo; interfaces claras; acoplamiento bajo.
5. **Escalabilidad honesta**: no sobre-diseñar para un futuro hipotético; el esfuerzo mínimo suficiente.
